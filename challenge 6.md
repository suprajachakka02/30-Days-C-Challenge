Algorithm
1. Start.
2. Declare a one-dimensional array and the required variables.
3. Read `N` and validate that it is between 5 and 12.
4. Read `N` array elements and validate that each element is between 0 and 1000.
5. Display the original array elements.
6. Calculate and display the sum, average, minimum, and maximum values.
7. Find and display the second-largest distinct value.
8. Count and display the local peaks in the array.
9. Find and display the longest strictly increasing continuous run.
10. Read the rotation value `K` and the last two digits `R` of the registration number.
11. Normalize `K` according to the array size.
12. Rotate the array to the right using the reversal method.
13. Display the rotated array.
14. Calculate `D = (R % 9) + 1`.
15. Count the elements divisible by `D`.
16. Display `D` and the count of divisible elements.
17. Stop.
