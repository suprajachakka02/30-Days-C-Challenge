1. Start.
2. Read `N`.
3. If `N` is less than 5 or greater than 15, print "Invalid N".
4. Read the ticket IDs.
5. Check whether all ticket IDs are within the range `1` to `N`.
6. Print the original sequence.
7. Find the missing ID and duplicate ID.
8. If the scan log is invalid, print "Invalid scan log".
9. Count the out-of-order pairs.
10. Read the last two digits of the registration number.
11. Calculate the target ID using `(R % N) + 1`.
12. Find and print the target ID positions and occurrence count.
13. Stop.
